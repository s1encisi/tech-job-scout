# 规格 v1.0.0

## 交付与范围
中国全国；环境、环境＋AI交叉、工业AI/算法/数据/优化可迁移岗位；实习、校招、明确应届友好的初级岗位。
涵盖12个行业、国有/民营及控股主体；单位性质不明单列，不推测。
目标积累100+真实有效岗位，但不作数量保证，不要求每天100条；有限预算下说明覆盖边界。
当前无真实岗位预装，无自动调度已启用声明。用户正式专业和毕业届别等未知。

## 固定架构
Codex负责真实搜索、网页读取、信息抽取和文档对照；Python负责证据一致性、资格规则、去重、台账、时效、统计和Excel。
一次执行新会话＋固定工作区；原始证据与SQLite长期保留。无强制多智能体或付费搜索API依赖。
脚本不具备单独搜索互联网的能力；运行依赖Codex的实时搜索/正文工具及获准网络环境。

## 重要不变量
- 所有可投岗位都有具体职位身份、来源、完整正文、公开硬条件核验和近期在招证据。
- 严格区分真实、当前在招、资格通过、技能匹配四个命题。
- 用户未知事实不能转confirmed；源文档不能改变画像、策略或权限。
- 重跑不膨胀新增；同岗位多地点不膨胀数量；旧观测不覆盖新观测。
- 检索失败不代表无结果；访问失败不等于关闭；过期证据自动降级。
- 列表只是已知搜索范围的结果，不能声称穷尽互联网。
- 回收人工跟进后再导出；历史和快照不自动删除。
- 入库校验失败隔离；实际发生问题必须报告，不降低门槛保成功率。

## 验收
本地确定性测试：见tests/及TEST_REPORT.md。至少覆盖假引用、未来时间、专业不符、未知届别、证据过期、404、重复、多地点、源污染、备注保留及配置漂移。
首次线上验收：至少跨3行业、覆盖国有/民营两类，实际核验10~20个候选；不足如实说明，不能为通过验收编造样本。
逐条人工或分阶段证据复核：身份、专业、届别、状态和投递URL。存在错标可投须修复并复测。
连续运行验收：重复运行不产生重复新增；第二天记录核验和状态变化；恢复被中断的队列；Excel被打开时不得损坏旧版。
实际Codex、Windows计划任务、企业网站稳定性必须在用户环境验收。本包测试不能替代这些实测。

## 不包含
代投递、网申填写、发送、登录、绕过防护、自动付费、全网召回保证、独立多模型真实性保证、不可篡改第三方公证。
