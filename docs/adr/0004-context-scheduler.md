# ADR-0004：新会话＋持久文件，调度与技能分离
状态：本交付采纳；日期：2026-09-15。
问题：无限续聊会积累过期状态、摘要漂移；skill本身不是守护进程。
决策：每天fresh Codex exec；按需加载SKILL/画像/策略/术语/当前checkpoint，正文从索引按需查。外部本地调度只触发run_daily.py。
代价：需要首次安装和实际调度接线；本地电脑停机时不能保证按点执行。
拒绝：自动resume --last作为唯一记忆、每天临时worktree丢状态、虚构ChatGPT能够直接写用户本地目录。
边界：CLI版本先预检，参数不兼容就停；模型/规则升级单独验证，不在日常自动改写。
