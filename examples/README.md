# 离线演示

从仓库根目录运行 `python examples/demo.py --output demo-output`。只使用标准库与 `tests/fixtures.py` 中的共享虚构证据，不运行测试套件、不调用网络或 Codex。

演示按顺序登记来源与职位证据、写入一个虚构岗位、重复写入同一观测、提交一条伪造引文、登记一个待核实入口，再生成 13 表 Excel 与备份。重复观测跳过，伪造引文隔离；没有执行的搜索任务保持未完成，因此报告为 `partial`。

运行结果见 `demo-output/demo-summary.json`。所有企业、职位和个人画像均为虚构，`example.test` 链接仅供结构校验，不能用于投递。生成目录属于本地输出，不随源码提交。重复体验时请换一个新输出目录，脚本不会覆盖已有文件。
